# Brand assets — provenance

Where each committed logo and cover-art file came from, so the next brand drop
is a re-run rather than a re-derivation. Source of truth for the originals is the
"Web Materials" Drive folder; the 2026-08 redesign arrived as a folder of
full-bleed PNGs and 4000×4000 JPEGs.

## Logos

The delivered wordmark/icon PNGs are 7680×4320 with the mark floating in the
middle of a mostly-empty canvas. Committing those as-is would render the logo at
a fraction of its box, so each one is **cropped to the bounding box of its
non-transparent pixels** before resizing — spacing around the mark belongs to
CSS, not to the file.

| Committed file | Source | Treatment |
| --- | --- | --- |
| `src/assets/logo-wordmark.png` | `Ark Media - Dark.png` (ink `#0e1532`) | crop to ink → 1200w. Used in the **light** theme. |
| `src/assets/logo-wordmark-light.png` | `Ark Media - Light.png` (ink `#fdfdfd`) | crop to ink → 1200w. Used in the **dark** theme. |
| `src/assets/favicon.png` | `Ark Media - Icon - Light.png` | crop to ink → centred at 66% on a `#0b153c` tile with a 22% corner radius → 512×512. |

Naming note: **Dark**/**Light** in the source filenames describe the *ink*, not the
backdrop — "Dark" is the near-black navy for light backgrounds. A third **Navy**
(`#005db7`) cut of both the wordmark and icon exists and is unused on the site.

The wordmark is ~6.8:1 (1200×177), a much wider lockup than the stacked
mark-over-wordmark it replaced. `ArkLogo` sizes by height class and relies on
`max-w-full` + `object-contain` so a narrow masthead scales it down instead of
squashing it — see the comment on that component.

## Delivered but not used on the site

- **`* - Cover Art - Ark+.jpg`** — each cover again with a `+` badge bottom-right.
  These are the members'/ad-free feed identity; nothing on the marketing site
  renders a badged cover today. They belong with the private-feed work.
- **`Ark+ - Dark.png` / `Ark+ - Light.png`** — the Ark+ lockup (~3.1:1). The site
  writes "Ark+" as live text everywhere it appears, so there is no image slot.
- **`Ark Media - Icon - *`** beyond the favicon, and **`Ark Media - Navy.png`**.
- **`Apple Podcasts/`** — channel background, channel/subscription icons, and the
  subscription promo. Apple Podcasts Connect artwork, not web assets.
